# Kaduna State University (KASU) Mapping Project

## Project Overview

This project involved creating a detailed map of Kaduna State University (KASU) from scratch during my internship at Geodetricks.

The project provided practical experience in field data collection, spatial referencing, manual digitization, ground-truthing, and GIS map production.

## Input

The project started with a study area image of Kaduna State University obtained from Google Earth.

![KASU Input Image](./KASU%20INPUT.jpg)

## Mapping Process

The mapping process involved:

1. Downloading the study area image from Google Earth.

2. Collecting at least 4–6 coordinates from different angles within the study area using a GPS waypoint mobile application.

3. Manually digitizing every building, footpath, road, parcel of land, and tree within the study area.

4. Revisiting the site for ground-truthing and collecting path coordinates for contour and other DEM-related analysis.

The interesting part of the project was that the mapping process had to be carried out manually.

## Output

The final output was a detailed digitized map of Kaduna State University showing the mapped features within the study area.
