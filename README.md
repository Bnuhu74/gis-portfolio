## Featured Projects

### 1. Kaduna Agricultural Mapping Project

A GIS project completed during my internship in 2022. The project involved manually digitizing information from an agricultural map of Kaduna State and converting the information into digital spatial data.

**Key activities:**
- Map georeferencing
- Manual digitization
- Creation of spatial datasets
- Assigning coordinate systems
- Map production and visualization

### 2. NDVI Analysis Using Sentinel-2 Data

A remote sensing assignment involving the use of Sentinel-2 satellite imagery to calculate and visualize the Normalized Difference Vegetation Index (NDVI).

**Key activities:**
- Sentinel-2 data exploration
- Image processing
- NDVI calculation
- Vegetation analysis
- Map visualization

### 3. Copernicus & Sentinel-2 Training

Practical learning experience focused on exploring Copernicus and Sentinel-2 Earth Observation data and understanding their applications in geospatial analysis and remote sensing.
